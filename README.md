# Wikipedia Search Application

A web-based Wikipedia Search Application built using HTML, CSS, JavaScript and Bootstrap. Users can search for topics and explore relevant results through clickable links.

## Features
- Search for topics using keywords.
- Display relevant search results with titles, URLs and descriptions.
- Show a loading spinner while fetching results.
- Open selected search results in a new browser tab.
- Clear previous results when performing a new search.
- Dynamically display search results using JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 4

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter a keyword in the search box.
4. Press Enter to view the search results.

## Project Purpose
Developed to practice frontend web development, JavaScript DOM manipulation, event handling, API requests and dynamic rendering of search results.
